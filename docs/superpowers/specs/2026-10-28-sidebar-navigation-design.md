# フォルダ対応サイドバー設計

## 目的

ホーム画面で単語帳が単体のタブとして横並びになる状態をやめ、フォルダを中心に単語帳を選べるようにする。既存の学習画面、カレンダー、整理・管理画面、クラウド保存形式は維持する。

## 採用案

- デスクトップでは左サイドバーを初期表示する。
- サイドバーは折りたたみボタンで細いアイコンバーにできる。
- モバイル幅では初期状態を折りたたみ、メニュー操作時に表示する。
- サイドバー上部に「ホーム」「カレンダー」「整理・管理」を置く。
- その下にフォルダを開閉可能なグループとして表示する。
- フォルダ内には所属する単語帳だけを表示する。
- フォルダに属さない単語帳は「未分類」にまとめる。
- 現在選択中の単語帳は背景色と左側のアクセントで示す。
- 単語帳をクリックすると既存の学習画面へ移動する。
- フォルダの開閉状態とサイドバーの折りたたみ状態は画面内で保持し、可能なら `localStorage` に保存する。

## 既存機能との関係

フォルダ名の変更、単語帳のフォルダ移動、単語帳や問題の整理は既存の「整理・管理」画面を引き続き利用する。サイドバーにはまずナビゲーションを実装し、編集操作を二重に持たせない。整理画面で変更した `folders` と `pages.folderId` はサイドバーへ即時反映する。

## データと状態

新しい永続データ項目は追加しない。`AppState.folders`、`Page.folderId`、`activePageId` を表示に利用する。UI状態として次を `App` または専用コンポーネントで管理する。

- サイドバーの開閉状態
- 各フォルダの展開状態

フォルダが削除された場合や単語帳が未分類になった場合も、表示時に安全に「未分類」へ振り分ける。

## 実装範囲

1. `Sidebar` コンポーネントを追加する。
2. `App` の横方向レイアウトをサイドバーとメイン領域に分ける。
3. 既存の単語帳タブ表示をサイドバーのフォルダ表示へ置き換える。
4. デスクトップ用の折りたたみ表示とモバイル用の表示を CSS で追加する。
5. フォルダ・単語帳選択のコンポーネントテストを追加する。

## 対象外

- フォルダの入れ子構造
- サイドバー上でのドラッグ＆ドロップ
- サイドバーからの直接的なフォルダ名変更・単語帳削除
- 新しいバックエンドテーブルやデータ移行

## 確認方法

- Sidebar のフォルダ開閉、単語帳選択、未分類表示をテストする。
- `npm test -- --run --maxWorkers=1` で既存テストを確認する。
- `npm run build` で本番ビルドを確認する。
