# 単語帳クラウド化 設計書

## 目的

パソコンを起動しなくても、スマホやPCから同じ単語帳を使えるようにする。
ログインした本人だけがデータを読めるようにする。

## 採用構成

- フロントエンド: Vercel
- 認証・データベース: Supabase
- UI: 既存のReactアプリを継続利用
- ローカルサーバー: 開発・緊急バックアップ用として残す

Supabaseはログイン、データ保存、アクセス制御をまとめて扱えるため、現在の構成からの移行量が少ない。

## データ設計

`flashcard_states` テーブルに暗記帳全体をJSONとして保存する。

- `user_id`: ログインユーザーID
- `state`: 現在の単語帳データ
- `updated_at`: 最終更新日時

Row Level Securityを有効にし、ログイン中のユーザーが自分の行だけ読み書きできるようにする。
現在の `data/anki-data.json` は初回移行時に読み込み、ローカルにもバックアップとして残す。

## 認証

- メールアドレスとパスワードでログイン
- 未ログイン時はログイン画面だけ表示
- ログアウトボタンを用意
- パスワードはアプリ内に保存しない
- Supabaseの接続情報は環境変数で管理する

## 同期

- 起動時にログインユーザーのクラウドデータを読み込む
- 問題追加、削除、進捗変更をクラウドへ保存する
- 保存完了前に古い同期結果で上書きしない
- 複数端末で開いている場合は定期的に最新状態を確認する
- 同時編集が起きた場合は、最後に保存した状態を採用する

## エラーとバックアップ

- 通信エラー時は画面に保存失敗を表示する
- ローカルJSONの書き出し・読み込み機能は残す
- クラウド移行前に現在のJSONを別名で保存する
- 文字化けしたデータは現在と同じく保存拒否する

## 移行手順

1. Supabaseプロジェクトを作成する
2. テーブルとアクセス制御を設定する
3. ログイン画面を追加する
4. 保存先をローカルAPIからSupabaseへ切り替える
5. 現在のJSONをログインユーザーのデータとして移行する
6. Vercelへ公開する
7. PCとスマホでログインして追加・再起動・同期を確認する

## 完了条件

- PCを起動していなくてもスマホからURLを開ける
- ログインしないと単語帳が表示されない
- 現在の暗記帳と問題がクラウドへ移行される
- スマホで追加した問題をPCでも確認できる
- 再起動してもデータが残る
- 文字化けデータを保存しない
- ローカルJSONバックアップを書き出せる
